# Правила дизайна Sprout

## Визуальный язык
- **Максимум визуала, минимум текста** — интерфейс должен говорить картинками, иконками и цветом, а не длинными текстами
- **Без обводок** — никогда не использовать `Border.all`, `BorderSide`. Выделение только через цвет фона, тени, blur
- **Без эмодзи в ядре интерфейса** — только системные иконки `Icons.*_rounded`
- **Шрифт** — строго `GoogleFonts.onest()` во всём приложении
- **Без англицизмов** — все надписи на русском языке. Вместо "Zero Waste" → "Не выбрасывать продукты", вместо "Low Carb" → "Низкоуглеводная"

## Компоненты
- Карточки — скруглённые углы 16–22px, цвет фона `AppColors.surface` / `surfaceMuted`
- Акцентные элементы — `AppColors.primary` с полупрозрачным фоном (alpha 0.08–0.15)
- Предупреждения — `AppColors.statusUrgent` с полупрозрачным фоном
- Виброотклик (`HapticFeedback`) при каждом действии пользователя
